# Project collaboration preferences

When the user says "commit and push", they authorize publishing the new task changes to this project's GitHub repository: `AlbertinoTheCoder/2D-Platformer`, remote `origin`, branch `main`. Complete the changes and relevant verification, commit the task files, and push them; a local commit alone does not fulfill the request. Preserve unrelated working-tree changes. Do not repeat a permission question for the routine push when this instruction applies.

For the Windows executable release task, the user also authorized making `AlbertinoTheCoder/2D-Platformer` public (including source and commit history), publishing the finished game ZIP as a downloadable GitHub Release, and documenting the download and build instructions in README.md.
